PHONE DROP — сайт для публикации

Быстрый запуск:
1. Распакуйте архив.
2. Откройте index.html в браузере для локальной проверки.
3. Для публикации на Netlify: зайдите на https://app.netlify.com/drop и перетащите папку с index.html (или сначала распакуйте ZIP).
   Также можно загрузить index.html в GitHub Pages.

Особенности:
- Нажатие на смартфон запускает следующий дроп.
- Тапы продолжаются без лимита, пока не выпадет легендарный или мифический телефон.
- При редком дропе серия автоматически останавливается; кнопка позволяет продолжить.
- Коллекция, баланс и история сохраняются в localStorage этого браузера.
- Все деньги игровые, цены ориентировочные. Внешняя база данных и синхронизация между устройствами не подключены.
